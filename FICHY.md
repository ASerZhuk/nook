# Фичи на будущее

## Каналы: боты Telegram / VK / MAX / Instagram (один бэкенд — разные фронты)

Идея: мастер подключает бота (токен Telegram, сообщество VK и т.п.) и получает тот же функционал, что в приложении. Бэкенд один, «фронтов» несколько.

### Архитектура

```
Приложение (PWA) ─┐
Telegram-бот ─────┤→ адаптер канала → общие сервисы (запись, слоты, клиенты, ИИ) → база
VK-бот ───────────┘                                         ↓
                              рассылка уведомлений ← события (запись / перенос / отмена)
```

- Адаптер канала принимает сообщение, ведёт диалог (услуга → день → время → контакты), вызывает те же функции, что и приложение, и отвечает кнопками своего мессенджера.
- **Самый дешёвый «другой фронт»** — мини-приложения Telegram и VK: внутри мессенджера открываются уже готовые страницы записи и кабинета почти без переделки. Бот тогда нужен только для уведомлений и быстрых команд («записать Анну завтра в 15»).
- **Главный плюс:** бот сам пишет клиенту о переносе или отмене — это закрывает проблему уведомлений для тех, кто пользуется этим мессенджером. Приложение и SMS-ссылка остаются запасным вариантом.

### Площадки

| | Что нужно мастеру | Сложность | Замечания |
|---|---|---|---|
| **Telegram** | Создать бота в @BotFather и вставить токен в nook | низкая | Кнопки, мини-приложение. Подтверждённый телефон через кнопку «поделиться контактом». Нестабилен в части СНГ |
| **VK** | Сообщество с включёнными сообщениями + ключ доступа к сообщениям | средняя | Бот пишет человеку только после того, как тот сам написал сообществу или разрешил сообщения. Мини-приложение VK проходит модерацию |
| **MAX** | Бот через платформу MAX | средняя | Актуален в РФ. Для ботов организаций, скорее всего, нужна регистрация юрлица/ИП — уточнить |
| **Instagram** | Одного id мало: бизнес-аккаунт, привязка к Facebook-странице, приложение Meta с проверкой | высокая | Meta признана в РФ экстремистской организацией — юридические риски. Отвечать можно только в течение 24 часов после сообщения клиента. Практичнее ссылка на запись в шапке профиля |
| WhatsApp | Business API через провайдера | высокая | Тоже Meta, платно за каждый диалог |

### Что меняется на бэкенде

1. **Общие сервисы.** Вынести логику записи из обработчиков API в функции, которые одинаково вызывают приложение и боты.
2. **Каналы мастера.** Таблица: тип канала, токен (зашифрованный), секрет вебхука, статус, имя бота / id сообщества. В кабинете раздел «Каналы» с инструкцией и кнопкой «Проверить».
3. **Вебхуки.** Отдельный адрес на каждого бота с проверкой подписи (Telegram — секретный заголовок, VK — строка подтверждения и секрет, Meta — подпись запроса). Защита от повторов: Telegram пересылает одно и то же обновление при ошибке.
4. **Состояние диалога.** Где клиент остановился (выбранная услуга, день), с ограничением по времени.
5. **Связка людей.** Кто этот пользователь Telegram/VK: клиент (его приложение, телефон) или сам мастер, подключённый по одноразовой ссылке-коду.
6. **Рассылка по событиям.** Запись создана / перенесена / отменена → уведомление во все подключённые каналы получателя. Сейчас уведомления уходят синхронно внутри запроса; с ботами нужна очередь с повторами и лимитами (у Telegram ~30 сообщений в секунду).
7. **Шаблоны сообщений под каждый мессенджер:** длина текста, число и вид кнопок.
8. **Инфраструктура.** Одного процесса и SQLite, скорее всего, станет мало: PostgreSQL, Redis для очереди и состояний, отдельный процесс для рассылки.

**Свой бот у каждого мастера или один общий?** Свой — брендинг, но хранение токенов и вебхуки на каждого. Общий бот nook проще: мастер получает ссылку вида `t.me/nook_bot?start=anna`. Разумно начать с общего, свой токен — опцией.

### Что нужно сделать владельцу

1. **Решить объём:**
   - каналы (предложение: Telegram → VK → MAX, Instagram под вопросом);
   - для кого бот: клиенты записываются, мастер получает уведомления и быстро записывает — или всё сразу;
   - общий бот или свой у каждого мастера.
2. **Боевой домен с HTTPS** — без него вебхуки и мини-приложения не работают, поэтому сначала деплой.
3. **Аккаунты платформы:** общий бот в Telegram, сообщество и приложение VK, при необходимости регистрация в MAX с данными организации.
4. **Юридическое:** политика обработки персональных данных и согласие клиента (152-ФЗ) — боты собирают телефоны; уведомление Роскомнадзора как оператора ПДн; по Instagram — отдельная консультация.
5. **Бюджет:** сервер с PostgreSQL и Redis, больше запросов к ИИ (разбор свободного текста в чатах), платные каналы вроде WhatsApp.
6. **Тексты для мастеров:** пошаговая инструкция «как получить токен» со скриншотами.

### Порядок работ

1. Фундамент: общие сервисы, события и очередь уведомлений.
2. Общий Telegram-бот: уведомления мастеру и клиенту, быстрая запись текстом, мини-приложение с текущими страницами.
3. Свой токен бота у мастера.
4. VK: бот сообщества и мини-приложение.
5. MAX.
6. Instagram — только если действительно нужно и юридически допустимо.
